# promo-prizes

Custom **carousel** block. Purpose: Golden-ticket prize slider: a title, then one slide per prize (title, copy, rules link beside a prize image) with dot pagination..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Rows holding a picture = a slide (picture cell = media; heading = title, CTA paragraphs = links, other paragraphs = body); any other row = slider title..

No variations.
