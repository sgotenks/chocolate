# promo-editorial

Custom **columns** block. Purpose: Golden-ticket editorial band: star-bracketed title, body copy and CTAs beside an image..

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: A text cell (heading = title, CTA paragraphs = links, other paragraphs = body) and a picture-only cell (media). In qr, a centred column with title, QR card and note..
