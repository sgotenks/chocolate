# product-cards

Custom **cards** block. Purpose: Alternating product cards with a "See more details" disclosure for ingredients and nutrition facts..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: One row per card: an image cell (product shot), a summary cell (name, title, description under an h2/h3) and a details cell (lead copy, then h4 groups: ingredients, nutrition facts list with nested sub-rows and bold daily values, small print)..
