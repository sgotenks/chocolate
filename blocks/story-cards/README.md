# story-cards

Custom **cards** block. Purpose: Section title over a row of frosted cards, each crowned by a round seal holding an icon..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Rows with an image = one card (image = seal icon, rest = card text); other rows = section head (heading and intro text)..

## Supported variations

No variations.
